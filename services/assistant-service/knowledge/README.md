# Assistant Knowledge

Esta carpeta está pensada para material listo para ser indexado/consumido por el `assistant-service`.

## Flujo sugerido

1. Guardar PDFs fuente en `docs/knowledge-base/pdfs/`.
2. Si luego hacés parsing/embeddings, copiar aquí los artefactos procesados.

## Nota

En esta etapa scaffold no hay pipeline de ingesta automática todavía.
