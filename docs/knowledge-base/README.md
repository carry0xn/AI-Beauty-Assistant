# Knowledge Base

Esta carpeta es la fuente de verdad para documentación de dominio (PDFs, apuntes y material de referencia).

## Estructura recomendada

- `pdfs/`: documentos fuente (colorimetria, facciones, peinados, etc.).

## Convención de nombres

Usar nombres en kebab-case, por ejemplo:

- `colorimetria-estaciones.pdf`
- `formas-de-rostro.pdf`
- `guia-peinados-segun-rostro.pdf`
